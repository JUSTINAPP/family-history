# Image-only listening

Supersedes the listening layout in fullscreen-memories.md. Home photos and Listen now open a full-viewport dark photo canvas with only two visible controls: Pause/Play and Close. The title remains an accessible dialog name but is not visually shown. Recording forms, speaker lists, seek bars, timers and detail links are absent from listening mode. Record a message still opens the existing recording view from Home; the caption still links to item details.

Voice memories play sequentially without merging their original files. Only one audio element is mounted. Pausing stops both voice and movement; closing unmounts playback and restores focus. With no audio, the photo still moves and the same button pauses/resumes the movement. Reduced-motion preferences disable the animation. Slow 32-second alternating zoom/drift replaces the previous subtle movement, with the image initially fitted to preserve its proportions.

The playback button shows a spinner during loading. A short status appears only while loading or when an error/autoplay restriction needs attention. Retry uses the same Play button; no persistent toolbar is introduced. Microphone recording, private source delivery, permissions and originals are unchanged. No migration or dependency required.
